# Skill — Guia MTE NR-01 / FRPRT (regras para o classificador)

Fonte: Guia MTE *Fatores de Riscos Psicossociais Relacionados ao Trabalho* (NR-1 / GRO).
Uso: grounding do motor e do LLM. **Não** substitui a NR vigente nem a validação técnica humana.

## Princípio

Avaliar **condições / organização / gestão do trabalho** no **grupo (GHE)**.
Nunca transformar em diagnóstico de saúde mental individual.

```text
ERRADO: trabalhador com alto risco de depressão / Burnout / CID
CORRETO: GHE X com exposição a excesso de demandas, baixa autonomia, suporte insuficiente
```

## Score da campanha ≠ grau do PGR

```text
questionário → indicadores → evidências → análise técnica → perigo → avaliação → inventário
```

Não usar pontuação CST como GE/GES/potencial, salvo critério documentado da organização.

## Catálogo (exemplificativo)

Só registrar fator se houver **evidência** (perguntas críticas, recorte, observação técnica).
Não presumir que todos os PSICO-* existem na empresa.

| Código | Fator |
|---|---|
| PSICO-001 | Assédio de qualquer natureza no trabalho |
| PSICO-002 | Má gestão de mudanças organizacionais |
| PSICO-003 | Baixa clareza de papel ou função |
| PSICO-004 | Baixas recompensas e reconhecimento |
| PSICO-005 | Falta de suporte ou apoio no trabalho |
| PSICO-006 | Baixo controle / falta de autonomia |
| PSICO-007 | Baixa justiça organizacional |
| PSICO-008 | Eventos violentos ou traumáticos |
| PSICO-009 | Baixa demanda / subcarga |
| PSICO-010 | Excesso de demandas / sobrecarga |
| PSICO-011 | Más relações no local de trabalho |
| PSICO-012 | Trabalho em condições de difícil comunicação |
| PSICO-013 | Trabalho remoto e isolado |

## Fonte / circunstância (anti-genérico)

Proibido: "trabalho", "rotina laboral", "fatores organizacionais" isolados.
Obrigatório: circunstância operacional do GHE (metas, ritmo, jornada, efetivo, interrupções…).

## Controles — hierarquia

Priorizar mudança na **organização do trabalho**:
revisar metas, redistribuir tarefas, dimensionar efetivo, pausas, autonomia, comunicação, suporte da gestão.

**Proibido como única medida:** palestra de resiliência, meditação, "orientar o trabalhador a controlar o estresse".

## Evidência insuficiente

Se não houver evidência suficiente para o GHE:

```text
INFORMAÇÃO INSUFICIENTE — REQUER VALIDAÇÃO TÉCNICA
```

Não completar lacuna por plausibilidade. Status Preliminar/Proposta.

## IA pode / não pode

Pode: organizar evidências, sugerir enquadramento, redigir causa/controles amarrados ao posto, mapear PGR.
Não pode: diagnosticar, inventar fonte/grau/severidade, declarar conformidade, inventar fator sem evidência.
